# backuppp

бэкапер.

массово копирует все файлы из папки в другую папку. 
При повторном запросе сравнивает хэш суммы всех файлов с сохраненными ранее и копирует только то, что изменилось.

многопоточка реализована через пул потоков. Пул не универсален и специально заточен под эту конкретную задачу, что позволяет:
1) легче дебажить
2) проще читать
3) легче понимать 
4) получить бОльшую производительность

## Зависимости

`libxxhash-dev`
